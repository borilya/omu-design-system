# Рендеры

**Статус:** ⬜ пусто

Изображения продукта плюс разбор: каждый рендер не просто лежит, а описан — что на нём, зачем он и какое правило визуала из него следует.

## Именование

`omu-<что>-<ракурс>-<версия>.<ext>` — например `omu-corpus-front-v2.png`. Версия обязательна: когда концепт меняется, старые рендеры остаются в истории, а не перезаписываются.
