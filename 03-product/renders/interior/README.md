# Интерьерные рендеры

**Статус:** ⬜ пусто — ждём файлы.

Сюда кладутся кадры продукта в интерьере: основной материал бренд-коммуникации. Правила регистра — в [02-identity/imagery.md](../../../02-identity/imagery.md).

## Как передать файлы

Любой из двух способов, разбор одинаковый:

1. Положить в [`_inbox/`](../../../_inbox/) в корне системы — это штатная точка входа, сортировать и переименовывать не нужно.
2. Оставить в любой папке и назвать путь — заберу оттуда.

## Чего в наборе не хватает

- Горизонтальных кадров: все шесть вертикальные, для лендинга нужны широкие.
- Крупных планов фактуры — шов, торец, ввод кабеля, нижняя грань с логотипом. Это же контент для highlight `Details` в Instagram.
