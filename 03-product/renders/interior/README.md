## Чего в наборе не хватает

- Горизонтальных кадров: все шесть вертикальные, для лендинга нужны широкие.
- Крупных планов фактуры — шов, торец, ввод кабеля, нижняя грань с логотипом. Это же контент для highlight `Details` в Instagram.
