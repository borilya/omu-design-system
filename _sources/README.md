# Архив первичных источников

Сюда складываются оригиналы, из которых извлечены правила: деки, скриншоты, экспорты Figma, ответы владельца и технические документы. Папка не заменяет живые ассеты в `04-assets/` и продуктовые файлы в `03-product/`.

## Как хранить

Имя файла:

`YYYY-MM-DD__<source-id>__<исходное-имя>`

`source-id` берётся из [`_meta/source-manifest.json`](../_meta/source-manifest.json). Оригинальное имя сохраняется в конце, чтобы источник можно было сопоставить с перепиской.

## После добавления

1. Заполни `repositoryFiles` и `sha256` в `_meta/source-manifest.json`.
2. Поменяй статус источника на `available`.
3. Обнови `_meta/sources.md`, `STATUS.md` и `_meta/changelog.md`.
4. Запусти `node scripts/check.mjs`.

## Ограничения

- Архив внутренних источников не входит во внешний handoff.
- Сертификаты, протоколы и электрические спецификации продукта живут в закрытом `03-product/evidence/`, а здесь хранится только исходный бренд-материал.
- Если репозиторий станет публичным, перед публикацией источники нужно вынести в закрытое хранилище, сохранив стабильные ID и контрольные суммы.
