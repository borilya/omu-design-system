Pill button for OMU calls to action — one primary per view; secondary and ghost carry everything else.

```jsx
<Button variant="primary" size="lg">Shop the strip</Button>
<Button variant="secondary">See the colors</Button>
```

Variants: `primary` (Black fill), `secondary` (hairline outline), `ghost` (text only), `inverse` (White fill, for Black surfaces). Sizes `sm | md | lg`. Hover = opacity 0.78; no scale, no shadow, no color shift. Label copy is sentence case with no exclamation mark.
