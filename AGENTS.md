# Инструкция для AI-агентов

Если тебя попросили установить или настроить дизайн-систему — выполни [`SETUP.md`](SETUP.md).

Перед любой работой прочитай `STATUS.md`, затем `CLAUDE.md`. `CLAUDE.md` — общая рабочая инструкция репозитория, несмотря на историческое имя файла.

Обязательные правила:

- `01-brand/brand-platform.md` — дословный канон владельца; не редактировать.
- Не выдавать `🟡` и `⬜` за утверждённые правила бренда.
- Не заполнять пробелы молча: гипотезу помечать `🟡` и добавлять в `_meta/open-questions.md`.
- При изменении правила синхронно обновлять `_meta/sources.md`, `STATUS.md` и `_meta/changelog.md`.
- Не коммитить файлы шрифтов: Desktop license TypeType запрещает их передачу. `@font-face` на публичном сайте — только с Web Font лицензией.
- Не публиковать продуктовые claims без допустимого доказательства из `03-product/claims.md`.
- Не менять checksum в manifest, пока не проверено, почему изменился сам первичный файл.
- После изменений запускать `node scripts/check.mjs`.
