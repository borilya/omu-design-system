# Установка для команды

Настройка делается одной фразой агенту — Claude Code, Codex или любому другому, у которого есть терминал.

## Что написать агенту

> Настрой дизайн-систему OMU по инструкции `SETUP.md` из https://github.com/borilya/omu-design-system. Шрифты лежат здесь: `<путь к папке или .zip со шрифтами>`.

Шрифты выдаёт владелец бренда отдельно — в репозитории их нет и не будет. Если шрифтов пока нет, вторую фразу можно пропустить: всё заработает на системном шрифте, шрифты подложатся позже той же командой.

## Инструкция для агента

Выполняй по порядку. Требуются `git` и Node.js 18+.

1. **Склонируй репозиторий**, если его ещё нет. Папку выбери вместе с пользователем, по умолчанию `~/omu-design-system`:

   ```sh
   git clone -c core.symlinks=true https://github.com/borilya/omu-design-system.git ~/omu-design-system
   ```

   Если репозиторий уже есть — `git pull` в нём.

2. **Разложи шрифты**, если пользователь дал путь. Скрипт сам найдёт нужные файлы внутри папки или архива, в любой вложенности:

   ```sh
   node scripts/setup.mjs --fonts "<путь>"
   ```

   Без пути запусти `node scripts/setup.mjs` — он покажет, чего не хватает.

3. **Если скрипт пишет, что симлинки не работают** — это Windows. Попроси пользователя включить Developer Mode (Settings → System → For developers) и склонируй заново командой из шага 1.

4. **Подключи скилл**, если агент их поддерживает — тогда бренд будет доступен и вне этой папки. Для Claude Code — симлинк, чтобы скилл обновлялся вместе с `git pull`:

   ```sh
   mkdir -p ~/.claude/skills
   ln -sfn ~/omu-design-system/06-design-system ~/.claude/skills/omu-design
   ```

   Путь подставь свой, если клонировал в другое место. В Codex тот же каталог `06-design-system/` подключается как скилл в `~/.codex/skills/omu-design`, если версия Codex поддерживает скиллы; если нет — пропусти шаг, Codex прочитает `AGENTS.md` прямо в репозитории.

5. **Проверь и покажи пользователю результат:**

   ```sh
   node scripts/check.mjs
   node scripts/setup.mjs --serve
   ```

   Открой пользователю ссылку на style guide из вывода. Сервер остановить — `Ctrl+C`.

6. **Коротко расскажи пользователю**, что настроено и как пользоваться — раздел ниже.

### Чего не делать

- Не коммитить шрифты и не класть их в другие места репозитория. Desktop license TypeType запрещает передачу файлов, а репозиторий публичный. `04-assets/fonts/` закрыт в `.gitignore` — не обходи это.
- Не пушить в `main`. Изменения бренда вносит владелец, порядок — [`CONTRIBUTING.md`](CONTRIBUTING.md).
- Не менять файлы под git во время установки. Скрипт установки их не трогает.

## Как пользоваться

**Сгенерировать что-то в стиле OMU** — лендинг, креатив, слайд, текст. Попроси агента открыть [`_ai/CONTEXT.md`](_ai/CONTEXT.md) и делать по нему. С подключённым скиллом достаточно сказать «сделай в стиле OMU». Вёрстку брать из [`06-design-system/`](06-design-system/): токены, компоненты, UI-киты.

**Посмотреть гайдлайн глазами** — `node scripts/setup.mjs --serve`, потом style guide в браузере.

**Обновиться** — `git pull` в папке репозитория. Шрифты при этом не пропадут.

Что важно помнить:

- **Материалы внутренние.** Носитель помечается как внутренний. Наружу — сайт, реклама, упаковка, маркетплейсы — только после [`RELEASE_CHECKLIST.md`](RELEASE_CHECKLIST.md): там другие правила по шрифтам и продуктовым claims.
- **Опираться только на `✅`.** Что уже решено, а что черновик — [`STATUS.md`](STATUS.md).
- **Язык бренда — английский**, имя в тексте — `OMU` капсом.
