# Происхождение правил

Для каждого зафиксированного правила — откуда оно взялось. Нужно, чтобы через полгода можно было понять, было ли это решением владельца или моей интерпретацией, и что перепроверить при смене концепта.

Стабильные ID первичных файлов, доступность и контрольные суммы хранятся в [`source-manifest.json`](source-manifest.json). Этот файл описывает смысловое происхождение правила; manifest отвечает за переносимость и целостность самого источника.

Тип источника: `решение владельца` / `выведено из файла` / `выведено из референса` / `предложение AI`.
