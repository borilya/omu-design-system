# Ассеты

Живые файлы бренда. Правила использования — не здесь, а в [`02-identity/`](../02-identity/).

| Папка | Что внутри | Правила |
|---|---|---|
| `logo/` | Логотипы во всех версиях и форматах | [logo.md](../02-identity/logo.md) |
| `fonts/` | Файлы шрифтов + лицензии | [typography.md](../02-identity/typography.md) |
| `images/` | Изображения бренда, кроме рендеров продукта | [imagery.md](../02-identity/imagery.md) |

Рендеры продукта живут отдельно, в [`03-product/renders/`](../03-product/renders/) — вместе со своим разбором.

## Правила папки

Один файл — одна роль. Никаких `logo_final_v3_ok.png`. Если появилась новая версия ассета, старая либо удаляется, либо уезжает в `_archive/` с датой — но не остаётся рядом с живой.

Для каждого шрифта рядом лежит лицензия. Без лицензии шрифт нельзя отдавать подрядчику.
