## `fonts/`

Правила: [typography.md](../02-identity/typography.md)

⚠️ **Файлов шрифтов в git нет и не будет.** Лицензия TypeType Desktop запрещает передавать файлы шрифта, а репозиторий публичный. Папка закрыта в `.gitignore`: всё, что положено сюда, остаётся только на твоей машине.

Как получить: попросить у владельца, если на твоё рабочее место хватает купленных мест. Положить сюда с этими именами:

| Файл | Роль |
|---|---|
| `TT_Bluescreens_Pro_Extended_Bold.woff2` / `.woff` / `.ttf` | Заголовки, 700 |
| `TT_Firs_Text_Normal.woff2` / `.woff`, `TT-Firs-Text-Normal.ttf` | Наборный текст, 400 |
| `licenses/` | PDF договоров Desktop license |

Тогда шрифты подхватят и токены, и `06-design-system/` — там `assets/fonts` ссылается сюда. Без файлов всё падает на системный фолбэк.

Desktop license покрывает статичные материалы на лицензированных машинах. Для `@font-face` на публичном сайте нужна отдельная Web Font лицензия: [typetype.org/licensing](https://typetype.org/licensing/).

## Чего не хватает

- Favicon и растровые размеры логотипа под соцсети.
- Совмещённая версия «знак + подпись `Hide nothing.`».
- Web Font лицензия TypeType для публичного сайта.

## Правила папки

Один файл — одна роль. Никаких `logo_final_v3_ok.ai`. Если появилась новая версия ассета, старая либо удаляется, либо уезжает в `_archive/` с датой — но не остаётся рядом с живой.

Шрифты не коммитим. Передать файл подрядчику можно, только если у него своя лицензия.
