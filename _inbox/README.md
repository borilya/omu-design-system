# _inbox

Свалка для сырья. Кидай сюда файлы как есть: рендеры, скриншоты, логотипы, шрифты, куски текста, PDF, экспорты из Figma. Не сортируй, не переименовывай, не думай о структуре — это моя работа.

Ссылки (Figma, диски, доски) складывай в `links.md` в этой же папке.

После разбора файл уходит на своё место в системе, а отсюда удаляется. Пустой `_inbox/` — признак, что всё вгруженное разобрано.

Альтернатива: оставить файлы где угодно и просто назвать путь — заберу оттуда. `_inbox/` нужен для того, чтобы не приходилось помнить, где что лежит.
