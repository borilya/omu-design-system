# Применения

**Статус:** ⬜ пусто

Как бренд выглядит в конкретных носителях. Раздел наполняется по факту: появился лендинг — появился `landing.md`.

Ожидаемые файлы:

- `landing.md` — структура и визуал сайта: сетка, блоки, поведение первого экрана.
- `social.md` — форматы соцсетей: обложки, посты, сторис, аватары.
- `presentation.md` — шаблон презентации: титул, контентные слайды, типовые схемы.
- `packaging.md` — упаковка, если у продукта она есть.

Каждый файл содержит правила плюс ссылку на живой пример — не абстрактную теорию.
