# Применения

**Статус:** 🟡 черновик — веб и соцсети описаны по слайдам деки. Презентация и упаковка не описаны.

Как бренд выглядит в конкретных носителях. Раздел наполняется по факту.

| Файл | Что внутри |
|---|---|
| [web.md](web.md) | Домен, SEO title и description, подтверждённый фича-блок из восьми плиток |
| [social.md](social.md) | Instagram: хендл, bio, highlights, характер сетки |
| [packaging.md](packaging.md) | Концепт графики упаковки, claims и открытые вопросы по маркировке |

Ожидается дальше:

- `presentation.md` — шаблон презентации. Дека бренда существует (слайды 333, 334 и далее), но пришла картинками: файлов нет.
- `marketplace.md` — карточка Amazon и Noon. Там категория «удлинитель», а не «интерьерный предмет», поэтому правила отличаются от лендинга.

Каждый файл содержит правила плюс ссылку на живой пример — не абстрактную теорию.
