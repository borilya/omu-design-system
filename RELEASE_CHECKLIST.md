# Чеклист внешнего релиза

Используется перед передачей материалов подрядчику, публикацией сайта, печатью или размещением карточки товара.

## Бренд и контент

- [ ] Все использованные правила имеют статус `✅`.
- [ ] Клиентские строки сверены с Verbal Identity в `01-brand/brand-platform.md`.
- [ ] Имя бренда в наборном тексте написано `OMU`.
- [ ] В макете нет стоп-слов и неподтверждённых обещаний.
- [ ] Все продуктовые утверждения разрешены в `03-product/claims.md`.
- [ ] Все доказательства из claims присутствуют в `03-product/evidence/manifest.json`, относятся к нужной ревизии и не истекли.

## Логотип, цвет и типографика

- [ ] Выбрана утверждённая версия логотипа для конкретного фона.
- [ ] Светлое значение логотипа согласовано с палитрой.
- [ ] Решено, что делать с C2PA-метаданными в SVG логотипа.
- [ ] Соблюдены утверждённые охранное поле и минимальный размер.
- [ ] Для печати используются утверждённые Pantone/CMYK, а не экранная выборка.
- [ ] Используются лицензированные файлы шрифтов; файлы шрифтов не входят в передаваемый пакет.
- [ ] Для публичного веба есть Web Font лицензия TypeType; иначе — только fallback-стек.

## Продукт и производство

- [ ] Указана актуальная ревизия продукта.
- [ ] Колорвей входит в утверждённый серийный список.
- [ ] Цвета деталей сопоставлены с физическими эталонами.
- [ ] Claims о мощности, зарядке, совместимости и безопасности подтверждены документами.
- [ ] Сертификационные обозначения сверены с актуальной инженерной документацией.

## Файлы и контроль качества

- [ ] Запущен `node scripts/check.mjs`, ошибок нет.
- [ ] Контрольные суммы в `_meta/source-manifest.json` и evidence manifest совпадают.
- [ ] Все ссылки и ассеты открываются на другом компьютере.
- [ ] В пакете нет `_inbox/`, локальных путей, временных файлов и внутренних комментариев.
- [ ] Растровые файлы имеют нужные размеры и цветовой профиль.
- [ ] Финальный PDF или макет просмотрен визуально после экспорта.
- [ ] Релиз записан в `_meta/changelog.md` и отмечен Git-тегом.
